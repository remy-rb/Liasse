# 08: Document view, download and filters

**What to build:** The Owner opens a Document and pages through it in the app, downloads its searchable PDF, and filters the Documents list by Category and Correspondent. Opening a Document can target a specific page, which Search and Citations will use.

**Blocked by:** 05 (Automatic filing)

**Status:** ready-for-agent

- [ ] Document view shows metadata and the pages, with page navigation
- [ ] A Document can be opened at a given page
- [ ] Download returns the searchable PDF from the Archive
- [ ] The list filters by Category and by Correspondent
- [ ] An Owner can only view or download their own Documents
- [ ] Backend and frontend tests cover view, page targeting, download and filters
